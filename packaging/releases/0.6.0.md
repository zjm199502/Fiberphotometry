FiberLume 0.6.0 是启用软件内补丁更新的首个基础安装版。使用 0.5.0 或更早版本，请先下载本页的 Windows x64 安装程序或 macOS Apple silicon 安装镜像。

- **检查更新**　打开“帮助 → 检查更新”。发现兼容补丁后，可在软件内下载，校验成功后可立即重启或下次启动时生效。遇到需要新基础版本的更新，软件会打开对应安装版的下载页。
- **Plexon 预览**　钙信号可选 `RawF_1` 或 `R_1`，对照通道可选 `F0_1`。选择后点击“读取”刷新图表。分析默认使用设备导出的 R 列作为 ΔF/F，也可以在预处理页选择从原始荧光重新计算。F0 是设备基线。
- **预览图操作**　左键或中键拖动平移。右键按住后向右拖放大横轴，向上拖放大纵轴。滚轮以指针为中心缩放，坐标轴刻度区域支持单轴调整，工具栏主页按钮恢复全图。
