# FiberLume 0.6.8 更新公告

本次更新适用于 Windows x64 和 Apple 芯片 Mac。已安装 FiberLume 0.6.0–0.6.7 的用户可打开 **帮助 → 检查更新**，选择下载补丁，完成后重启。重启后窗口标题显示 **FiberLume 0.6.8**。

### 更容易看清当前步骤

五个主流程页签使用深蓝色标出当前步骤。读取页的“通道与选区”和“原始预览”有独立边框。常见 1080p 桌面下，参数、波形和统计图按可用空间并排或分页显示。长试次表、事件表和日志可独立滚动。从预处理返回选择信号区间时，对应按钮会完整显示。

### 刺激锁定窗口与补打标

每个试次自动覆盖基线窗、目标窗和刺激零点。默认基线为 −5～0 秒、目标为 0～5 秒，波形和热图显示 −5～+5 秒。调整窗口后重新运行，峰值、AUC 和逐试次导出同步更新。

在数据读取页添加手动 TTL 后，进入 **③ 刺激锁定分析 → 对齐的打标**。选择例如 **Untitled + 手动 TTL**，即可合并该文件通道与本记录补标。两种标记落在同一采样帧时计一次，保留文件边沿时刻。逐试次表给出每个事件的来源。也可单独选择文件通道或手动 TTL。

### 预览图可直接编辑

双击图中的标题、轴标签、图例、曲线或热图，即可编辑文字、字号、系列颜色或热图色带。工具栏的 **编辑** 可以按名称选择元素，**保存** 可以导出改好的图。修改仅涉及图形外观，分析继续使用原始数值。

### 在软件外重画分析图

- **③ 刺激锁定分析 → 试次 → 绘图数据包** 导出每个试次的 ΔF/F 和基线 Z 分数、相对时间、均值、SEM、峰值、AUC 和配对统计。
- **④ 事件检测 → 事件列表 → 绘图数据包** 导出逐样本荧光、去噪信号、推断活动、阈值、逐事件幅值与 AUC、直方图分箱及可用的刺激前后频率比较。本页 Z 分数以当前处理段的有限荧光值为参照。

解压 ZIP 后可用 R、Origin 或 Python 读取 CSV。随包的说明、坐标和参数记录以及独立 Python 脚本可用于重绘。各包使用当前页面已运行的结果。
